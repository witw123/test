# 贪吃蛇小游戏

这是一个使用原生 HTML、CSS、JavaScript 实现的贪吃蛇游戏，支持计分、暂停与最高分记录。

## 玩法

- 使用方向键或 **W/A/S/D** 控制移动方向。
- 按 **空格键** 暂停/继续游戏。
- 点击“重新开始”或结束弹窗中的按钮可重新开局。

## 运行方式

直接在浏览器中打开 `index.html` 即可运行。

如果需要本地静态服务，可以执行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/index.html`。

## 说明

- 吃到食物会增加长度与分数。
- 撞到墙壁或自身会结束游戏。
- 最高分会保存到浏览器的 `localStorage` 中。
